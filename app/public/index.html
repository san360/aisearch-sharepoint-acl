1 · Ingestion (least privilege, no secrets)

  • Ingestion app has Sites.Selected (Graph + SharePoint) — admin-consented.
  • Access is granted per site with POST /sites/{id}/permissions. HR is never granted.
  • The indexer authenticates through a federated identity credential that trusts the search service's managed identity.

2 · ACLs travel with every chunk

  • Data source: indexerPermissionOptions: ["userIds","groupIds"].
  • Index fields with permissionFilter and permissionFilterOption: enabled.
  • Index projections copy ACLs to each chunk; SharePoint site groups are stored as spg: IDs.

3 · Enforcement at query time

  • The app's identity authorises the call; the user's token goes in x-ms-query-source-authorization.
  • Search expands transitive Entra groups (Graph) and SharePoint site groups, then filters before ranking.
  • No user token → no ACL-protected results. Failures return 5xx, never partial results.

4 · Freshness

  • Indexer runs on a schedule (default every 15 min, minimum 5 min).
  • New/changed files and item-level permission changes: picked up on the next run.
  • Site/library/folder (parent-scope) changes: /resync with permissions.
  • Entra group membership changes: immediate — resolved at query time.
